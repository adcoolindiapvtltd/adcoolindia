## 🚀 Deployment Instructions (Quick Reference)

### Three Simple Steps:

```bash
# 1. Create GitHub repository (at github.com)
# Name: adcool-website | Public | No README

# 2. Push code to GitHub
cd "path/to/adcool-website"
git add .
git commit -m "Initial AdCool website commit"
git remote add origin https://github.com/USERNAME/adcool-website.git
git push -u origin main

# 3. Enable GitHub Pages
# Go to: Repository Settings → Pages
# Branch: main | Folder: /(root)
# Save → Wait 2-3 minutes → Live!
```

**Your website will be live at**: `https://username.github.io/adcool-website/`
