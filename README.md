# AdCool Products website

Static marketing website for AdCool Products, ready to deploy with GitHub Pages.

## Publish with GitHub Pages

1. Create a new GitHub repository and push this folder to its `main` branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/(root)` folder, then save.

GitHub will publish the site at `https://<username>.github.io/<repository-name>/` for a project repository, or `https://<username>.github.io/` for a user repository.

## Before publishing publicly

Replace every occurrence of `https://www.example.com` with the final public site URL. These values appear in canonical tags, structured data, `robots.txt`, and `sitemap.xml`.

Also replace the contact-detail placeholders on the contact page with AdCool's real business details.

## Local preview

Open `index.html` in a browser, or serve this folder with any static-file server.

The `.nojekyll` file ensures GitHub Pages serves the site files exactly as written.
